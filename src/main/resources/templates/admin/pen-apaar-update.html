Supports .xls and .xlsx formats

The sheet must contain a PEN No column plus an Apaar ID column. Student Name / Gender / DOB / Mobile / Class / Section columns, if present, are shown for your reference only — they are never used to match or block the update, since only PEN No is treated as a reliable match key. No school needs to be selected first.
How Each Row Is Handled
  • READY — no existing value. Updated.
  • CONFLICT — DB already has a different Apaar ID, or the PEN No matches more than one student. Never auto-updated, listed for manual review.
  • SKIP — sheet value is blank, or already matches the DB. Left untouched.
  • ERROR — PEN No missing/not found, or value fails the digit-format check.
