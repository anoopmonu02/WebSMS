Birthday notification

Every day at the time below, the system finds students whose birthday is today and sends a "Happy Birthday" notice on the parent app.

One time for all schools / branches
24-hour clock, server local time. Takes effect from the next run, no restart needed.
 
How it works

At send time: every school is checked for birthdays today.

Who gets it: parents of those students, on the parent app.

Changing the time: applies from the next run, for all schools.

Admin only. Only Admin and Super Admin can see and change this time.
