Supports .xls and .xlsx formats

The sheet must contain a PSRN# column plus the column matching your selected update type (PEN No or Apaar ID). Student Name / Father Name / Mother Name / Grade / Sec columns, if present, are used only to flag mismatches for your review — they never block the match. PSRN is matched globally, no school needs to be selected first.
How Each Row Is Handled
  • READY — no existing value, no mismatch. Updated.
  • WARNING — name/father/mother/grade/section differ. Updated only if you confirm.
  • CONFLICT — DB already has a different value. Never auto-updated, listed for manual review.
  • SKIP — sheet value is blank, or already matches the DB. Left untouched.
  • ERROR — PSRN missing/not found, or value fails the digit-format check.
